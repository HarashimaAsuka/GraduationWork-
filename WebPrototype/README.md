# 精霊馬タクシー 地獄営業所 — Web版の試作（v43）

`v43/index.html` をブラウザで開くと遊べます（インターネットにつながっている必要があります。three.js を読み込むため）。
BGM は `v43/bgm/` の3曲（sneak＝行き、chase＝帰り、boss＝決戦）。ファイルを直接開くとブラウザの制限で BGM が鳴らないことがあるので、そのときは公開ページで遊んでください。
（v42 は git の履歴に残っています）

## ルール（Unity版 `Assets/Scripts/IllegalTaxi/` と同じ）
- **行き（きゅうりの馬）**：罪人の魂に触れて乗せ、奥の「現世の門」へ。魂は何人でも乗るが、乗せるほど遅くなる。運賃は白10・黄20・紫30文。紫の魂のすぐ先には巡査が見張っている。警察にぶつかると魂を1人捕まえられる。警察のすぐ脇を抜けると、車掌が財布から小銭をスる（+2文）。
- **制限時間**：お盆の夜が明けるまで（研修200秒・一日目150秒・二日目140秒）。間に合わないと「夜が明けた」で失敗。
- **現世の門**：運賃をもらい、水分も回復。そのあと通報され、ナスの牛に化ける。
- **帰り（ナスの牛）**：大警部から手前の「地獄の門」まで逃げきる。牛は警察を吹っ飛ばせるが、運賃を10文落として少し止まる。大警部に追いつかれたら即ゲームオーバー。
- **判定**：地獄の門で売上が目標以上なら黒字（クリア）、星1〜3で評価。足りなければ赤字。帰り道には救済の「落とし物の小銭」（足りない分の6割ぶん）が出る。2回続けて負けると「お守りを持って再挑戦」が出る。
- **ステージ**：1 研修・2 一日目（夕暮れ）・3 二日目（雨と稲光）・4 大警部との決戦（ふだんは白手袋で顔を守る。攻撃してくる瞬間がスキ。叩きつけ・薙ぎ払い・突進・護衛）。
- **操作**：WASD 移動、左クリック / Z 塩（画面のまんなかの照準へ飛ぶ）、P 一時停止、R やり直し、Enter 次へ、M 音。
- **社名**：はじめて遊ぶときに「○○タクシー」の○○を決める（タイトル・一時停止から変えられる）。
