# 精霊馬タクシー 地獄営業所 — Web版の試作（v42「違法タクシー」）

`v42/index.html` をブラウザで開くと遊べます（インターネットにつながっている必要があります。three.js を読み込むため）。
BGM は `v42/bgm/` の3曲（sneak＝行き、chase＝帰り、boss＝決戦）。ファイルを直接開くとブラウザの制限で BGM が鳴らないことがあるので、そのときは公開ページで遊んでください。

## ルール（Unity版 `Assets/Scripts/IllegalTaxi/` と同じ）
- **行き（きゅうりの馬）**：罪人の魂に触れて乗せ、奥の「現世の門」へ。魂は何人でも乗るが、乗せるほど遅くなる。運賃は白10・黄20・紫30文。警察にぶつかると魂を1人捕まえられる。
- **現世の門**：運賃をもらい、水分も回復。そのあと通報され、ナスの牛に化ける。
- **帰り（ナスの牛）**：大警部から手前の「地獄の門」まで逃げきる。牛は警察を吹っ飛ばせるが、運賃を10文落として少し止まる。大警部に追いつかれたら即ゲームオーバー。
- **判定**：地獄の門で売上が目標以上なら黒字（クリア）、足りなければ赤字。帰り道には救済の「落とし物の小銭」（1枚5文）が出る。
- **ステージ**：1 研修（チュートリアル）・2 一日目・3 二日目（雨と稲光）・4 大警部との決戦（白手袋の叩きつけ・薙ぎ払い・突進・護衛など）。
- **操作**：WASD 移動、左クリック / Z 塩（白い輪の先へまっすぐ飛ぶ）、P 一時停止、M 音。
